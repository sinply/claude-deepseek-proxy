Claude DeepSeek Model Rewrite Proxy

A local proxy that lets Claude-3p keep Claude-compatible model aliases while DeepSeek receives the real Anthropic API model names.

How It Works

  1. Claude-3p sends requests to http://127.0.0.1:8787.
  2. The proxy forwards the request to https://api.deepseek.com/anthropic.
  3. Only the JSON model field is rewritten when it matches a known alias.
  4. Headers, message content, tool parameters, streaming flags, and responses are forwarded.

Model Mapping

Claude Alias DeepSeek Model
claude-deepseek-v4-pro deepseek-v4-pro
cluade-deepseek-v4-pro deepseek-v4-pro
claude-deepseek-v4-flash deepseek-v4-flash
cluade-deepseek-v4-flash deepseek-v4-flash

Claude-3p Configuration

Set the gateway base URL to the local proxy:

http://127.0.0.1:8787

Keep Claude-compatible model names in the model list:

[
  { "name": "claude-deepseek-v4-pro", "supports1m": true },
  { "name": "claude-deepseek-v4-flash", "supports1m": true }
]

Start In Background

Manual start:

powershell -ExecutionPolicy Bypass -File .\start-claude-deepseek-proxy.ps1

The script starts node.exe as a hidden background process and exits. If port 8787 is already listening, it will not start another copy.

Autostart

Install or repair the Windows scheduled task:

powershell -ExecutionPolicy Bypass -File .\install-autostart.ps1

Check status:

powershell -ExecutionPolicy Bypass -File .\status.ps1

Remove autostart:

powershell -ExecutionPolicy Bypass -File .\uninstall-autostart.ps1
The scheduled task may show Ready after it runs. That is expected because the task starts the hidden Node proxy and exits.

Security Notes

  • This is not a system proxy.
  • Only software explicitly configured to use http://127.0.0.1:8787 is affected.
  • API keys are not stored in this repository.
  • Runtime logs are written to proxy.log, which is ignored by Git.
